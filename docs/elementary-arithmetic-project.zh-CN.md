# 小学竖式动画教学技能

状态：已立项，V0.1 本地预览可用。日期：2026-10-26。

## 目标与范围

用户输入两个整数和运算符，得到可离线打开、可换题、可逐步播放的完整竖式计算动画。首版覆盖 0—9999 的非负整数；减法结果非负；除法输出商和余数。支持连续进位、跨零退位、多位数乘法、商中间为零。

## 引擎调研与决策

以下是基于官方文档的适配判断，并非实测性能排名。

| 方案 | 官方能力 | 本项目判断 |
|---|---|---|
| [Manim Community](https://docs.manim.community/en/stable/index.html) | Python 编程制作数学图像和视频 | 适合后续视频导出；浏览器即时换题需要额外服务 |
| [GSAP Timeline](https://gsap.com/docs/v3/GSAP/Timeline/) | 时间线、嵌套、播放/暂停、进度、倍速 | 选用：适合编排数字出现、进退位标记与教学停顿 |
| [Anime.js](https://animejs.com/documentation/timeline/) | 动画/计时器/回调同步、时间线 | 可行替代，本期不同时引入多个动画库 |
| [Motion](https://motion.dev/docs/animate) | HTML/SVG 动画、序列和播放控制 | 可行替代，当前无 React 需求 |
| 浏览器原生动画 | 原生 DOM/SVG 动画 | 可减少依赖；复杂教学时间线需要自行封装 |

采用确定性 JavaScript 求解器 + SVG 竖式 + GSAP 3.13.0 时间线。固定版本并内嵌到 HTML，保证离线使用。GSAP 采用其自身标准许可，详见 skill assets/THIRD_PARTY.md。数学正确性不依赖动画库。

## 设计

浅色练习本、墨绿结果、橙色进退位，大字数字。左侧题目输入与典型案例，右侧竖式、当前解释和播放控制。移动端上下布局。

求解器输出完整状态快照：行/数位/数字、进退位标记、当前高亮、讲解和公式。播放器按快照重建场景，避免上一步和重播时状态残留。修改题目后取消时间线。减少动态效果偏好下跳过数字入场动画。

## 阶段

- V0.1：四则整数、单文件生成、分步/自动播放、引擎测试、浏览器预览。
- V0.2：已加入加减法积木合十、拆十、跨零逐级拆分和拿走演示；后续调整进退位箭头、课堂投影布局，并由小学教师复核讲解。
- 后续可选：小数、语音讲解、视频导出；需分别明确精度、配音和渲染流程。

## 运行与验收

```bash
python3 skills/elementary-arithmetic-animation/scripts/generate_arithmetic_html.py --output examples/elementary-arithmetic.html
node tests/arithmetic.test.cjs
```

验收题：999+1、1000−586、48×27、306×20、1005÷5、17÷5、3÷8、8÷0。自动测试核对最终竖式数字、乘法部分积、商余恒等式及边界。人工检查进退位位置、播放/暂停、倒退、换题、移动端及离线打开。

## 当前边界

无小数/负数、语音或 MP4。乘法零行保留作为教学步骤。进退位数字提供入场动画，已增加加减法积木拆合，尚未实现沿曲线飞行的进位演示。长除法随步骤增加缩放保留完整过程，四位数除法投屏可读性仍可进一步优化。

积木元数据与竖式共用步骤快照。2010 道算式回归同时检查拆合的数量守恒与减法拿走的边界。浏览器验证 14 个一合成 1 个十及 4 个一、跨零连续拆分、倒退、独立重播和拿走，390px 无横向溢出。乘除法不展示加减法积木。

## 手机端布局

600px 以下采用紧凑双列数字输入、至少 44px 的主要触控按钮、带安全区留白的底部固定播放栏。竖式画布按当前数位收紧 SVG 视野，长竖式在画布内纵向滚动；积木的高低数位上下排列，明确标注块值。提交算式后收起键盘并定位到教学区。保留用户缩放能力，减少动态效果偏好下不做平滑滚动。

浏览器模拟宽度 320、390、430、768、1280px 已检查，无页面横向溢出；手机固定控制栏、积木切换、跨零退位通过。桌面保持原有双栏画布布局。安全区与软键盘使用浏览器支持的 viewport-fit、env() 和 blur() 处理，尚未经实体 iOS/Android 设备验证。

## 视觉主题：Math Orbit

用户希望视觉更炫酷，预览切换为深蓝数学实验舱：薄荷绿表示当前数位与结果，琥珀色表示进退位，暗色网格、发光积木、轨道标识和播放按钮增强辨识。主题集中在 assets/theme.css，由生成器内嵌，保持离线能力。布局和数学步骤不变；入场效果尊重减少动态效果偏好。手机底部播放栏沿用安全区适配。
